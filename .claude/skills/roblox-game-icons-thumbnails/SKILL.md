# Game page
- Icon 512×512 (square, readable at 100 px: one big character + bright background + 1–2 words max). Thumbnails 1920×1080 (16:9), up to 10.
- Renders: Forge Blender `map … --render 1920` gives cover.png + icon.png; pet renders on blue studio backdrop.
- Title: short, keyword first ("Pet Hatch Simulator 🥚"), emoji sparingly. Description: first 2 lines matter (what you do + reward loop), then codes and updates.
- Update from iPhone: Roblox Push → game page (meta action: name, description, icon, thumbnails as Image assets).
- Moderation can take minutes; avoid text-heavy images.
