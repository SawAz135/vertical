Roblox Push

Publie un jeu Roblox depuis ton iPhone

1Connexion GitHub

non connecté

GitHub sert de relais gratuit : Safari ne peut pas parler directement à Roblox. Il faut un jeton GitHub (une seule fois).

  1. Ouvre github.com › nouveau jeton
  2. Repository access : Only select repositories › ton dépôt
  3. Permissions : Actions Read · Contents Read and write · Secrets Read and write · Workflows Read and write
  4. Generate token, copie-le et colle-le ici

2Installation dans le dépôt

—

Crée la branche roblox-push avec le robot de publication. À refaire seulement si l'app te le demande.

3Clé Roblox

—
  1. Ouvre create.roblox.com › Credentials › Create API Key
  2. Access Permissions : universe-places › ton jeu › write. Pour le test Luau, ajoute aussi luau-execution-sessions › write
  3. Security : laisse Restrict IP addresses désactivé
  4. Save & Generate Key › Copy, colle ici

La clé est chiffrée sur ton iPhone puis rangée dans les secrets GitHub. Elle n'est jamais gardée par l'app.

4Jeu et fichier

—
Choisir un fichier .rbxl · .rbxlx · .zip (projet Rojo ou place)
