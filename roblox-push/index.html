    Aide

    Où trouver un fichier de jeu sur iPhone ?
    Dans l'app Fichiers d'Apple. Trois façons d'en avoir un :
    • Demande à Claude (onglet Code) : « crée-moi un jeu Roblox ». Il construit le jeu sur GitHub ; ouvre le dépôt › Actions › le dernier passage › Artifacts › télécharge le .zip. Dépose ce .zip directement ici, l'app sait le lire.
    • Un .rbxl qu'un ami t'envoie (AirDrop, Discord…) : enregistre-le dans Fichiers.
    • N'importe quel dossier de scripts (.lua / .luau) compressé en .zip : appui long sur le dossier dans Fichiers › Compresser. Pas besoin de fichier de projet : le robot range tout seul les scripts dans les bons services Roblox et ajoute un sol si le jeu n'en a pas.
    C'est vraiment gratuit ?
    Oui, 0 €. GitHub Actions est gratuit (2 000 minutes par mois pour un dépôt privé, illimité pour un dépôt public ; une publication prend environ 1 minute). L'API Roblox est gratuite. Aucune carte bancaire.
    « En ligne » ou « Brouillon » ?
    En ligne : les joueurs voient la nouvelle version tout de suite. Brouillon : la version est enregistrée sur Roblox mais pas encore visible ; parfait pour tester.
    Je me suis trompé de version, je peux revenir en arrière ?
    Oui. Roblox garde l'historique : create.roblox.com › ton jeu › Places › ta place › Version History › Restore. Ou republie l'ancien fichier avec l'app.
    « Roblox refuse la clé »
    Sur create.roblox.com › Credentials : la clé doit être Active, avec Restrict IP addresses désactivé et universe-places › ton jeu › write. Si besoin, régénère-la puis colle-la dans Réglages › Clé Roblox.
    Les joueurs ne voient pas la mise à jour
    Les serveurs déjà ouverts gardent l'ancienne version. Quitte le jeu et relance-le, ou attends que les anciens serveurs se ferment.
    Est-ce que c'est sûr ?
    Ta clé Roblox est chiffrée sur ton iPhone avant d'aller chez GitHub, qui la garde en secret. L'app ne la garde jamais et ne parle qu'à GitHub. Le jeton GitHub reste sur ton iPhone ; « Se déconnecter » l'efface.
